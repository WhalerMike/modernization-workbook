# Archive {.unnumbered}

The site always shows the current workbook. An **edition** is a fixed copy of it: a tag on the repository, named for the month it was cut (`edition-2026.10`; a second cut in the same month is `edition-2026.10.1`), and a GitHub Release that keeps that edition's built files: the Word editions of the books, the presentation decks, the narration audio and the videos. Nothing in a Release changes after it is published, so a link to an edition's file, or to the source at an edition, keeps pointing at the same thing.

Each book, guide and developer workbook ends with its **version and revision history**: version 1.0 in the first edition it appears in, one step up in each edition that changes it, and the changes in each. Every change between editions, however small, is in the repository's [commit history](https://github.com/WhalerMike/modernization-workbook/commits/main).
