# Downloads {.unnumbered}

Everything here is free to download. The kits and the Word editions are rebuilt from the same sources as the site, so a download always matches the page you read.

## Kits

| Kit | What's in it | Download |
|---|---|---|
| **Start Kit** — read-only estate assessment | PowerShell scripts that count the forest, the SQL Server estate, and RADIUS and NPS, with a one-page summary traced to its sources. Read-only by policy; unit-tested against fixtures, not proven against a live estate. See [Book 00, Chapter 08](books/b00-orientation/08-pre-flight-and-assessment.md). | [start-kit.zip](../downloads/start-kit.zip), rebuilt on every site deploy from [`examples/start-kit`](https://github.com/WhalerMike/modernization-workbook/tree/main/examples/start-kit) |
| **Help Desk / Cloud Services Entra ID Operations Kit v1.6** | Four Word documents (intake and routing flow, administrative responsibilities, application access governance, governance structure brief), the routing matrix as a PowerShell module, the scripts with plain-text copies for mail systems that block `.ps1` files, and Pester tests that need no tenant. Applies the help-desk model in [Book 15](books/b15-day2-operations/index.md). Not tenant-tested: run every change script with `-WhatIf` first. | [helpdesk-entra-operations-kit.zip](https://github.com/WhalerMike/modernization-workbook/releases/download/helpdesk-entra-kit-v1.6/helpdesk-entra-operations-kit.zip) · [release notes](https://github.com/WhalerMike/modernization-workbook/releases/tag/helpdesk-entra-kit-v1.6)<br>SHA-256 `99bd1f8ff514aea71d0b47b716dc5822f894368c3c2636fc3a169ac98ef27b1a` |
