# Module 4: An agent that only proposes {.unnumbered}

*Part of the [Application Modernization learning path](index.md). Book 18, [Chapter 05](../../books/b18-application-modernization/05-generative-and-agentic-ai.md). ## Introduction (3 minutes)

The model decides what to ask for; code the agency controls decides what runs. In this module you run the reference implementation's triage agent, read its proposal and its audit, watch a decision in the agent's own name refused, and make the model ask for a tool it was never offered, loop forever and inject an argument.

**The federal requirement.** The output of this module's lab is evidence for these controls; your organization still sets their parameters, policy and procedures, and the assessor decides whether each is satisfied. The workbook chapter's [Federal requirements and evidence](../../project-plans/developer-workbooks/application-modernization/04-an-agent-that-only-proposes.md#federal-requirements-and-evidence) table has a row for each lab step, and the kit's `config/requirements.json` holds the mapping.

| Requirement | KSI | Evidence |
|---|---|---|
| AC-6, Least Privilege | KSI-IAM-ELP | The allow-list in `application.yml`; the denied calls in the audit |
| AU-2, Event Logging; AU-12, Audit Record Generation | KSI-MLA-LET | `audit-triage.csv` and `audit-guardrails.csv`; the `agent_audit` table |
| OMB M-25-21, human oversight of high-impact AI | — | The decisions recorded by a person |

KSIs are FedRAMP 20x indicators for cloud service providers. The agency lines this evidence up with what its providers report against them; it doesn't report KSIs itself. Which file supports which indicator is the program's mapping *(design guidance)*.

## Learning objectives (1 minute)

After this module, you'll be able to:

- name the guards an agent that calls tools needs, and where each sits in the kit;
- read the audit and say which calls ran, which were denied and why;
- show that no case changed until a person decided;
- explain what changes before production: the decider from the signed-in user, a real model adapter, a workload identity.
