# Module 2: Consent requests and the approver {.unnumbered}

*Part of the [Help Desk Automation learning path](index.md). Book 15, Chapter 12, task 3. Workbook [Chapter 02](../../project-plans/developer-workbooks/help-desk-automation/02-the-consent-request-review.md). About 35 minutes.*

## Introduction (3 minutes)

An admin consent request asks for an application to be given access to the agency's data. Book 15 puts the decision with the identity governance approver, after the service's authorization is recorded, and never with the help desk. What a machine can do is make the waiting requests visible: who asked, for what, and for how long.

In this module you review the fixture tenant's pending requests, read the register and its findings, and run the review as the platform host's scheduled job would.

**The federal requirement.** The review supports AC-6, AC-20, CA-7 and SA-9; the assessor decides each. The chapter's [Federal requirements and evidence](../../project-plans/developer-workbooks/help-desk-automation/02-the-consent-request-review.md#federal-requirements-and-evidence) table has a row for each output.

| Requirement | KSI | Evidence |
|---|---|---|
| AC-6: the review reads and can't decide | KSI-IAM-ELP | `Get-HtRequiredPermission -Task consent-requests` |
| CA-7; AC-20; SA-9: every pending request, on a schedule, with the ones to decide now | KSI-IAM-ELP | `register.json`, `register.csv`, `findings.json`, `manifest.json` |

KSIs are FedRAMP 20x indicators for cloud service providers; the agency lines its evidence up with them and doesn't report them *(design guidance)*.

## Learning objectives (1 minute)

After this module, you'll be able to:

- name the one permission the review needs;
- read the register and say which request is overdue and which is broad;
- check a file's hash against the run's manifest;
- say who decides a request the review flags.

    ```powershell
    (Get-Content "$Run\consent\findings.json" -Raw | ConvertFrom-Json) | Format-List Rule, Severity, Issue | Out-String -Width 400
```
