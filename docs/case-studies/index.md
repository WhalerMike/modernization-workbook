# Case Studies {.unnumbered}

These narratives illustrate intended modernization behavior using synthetic
agency archetypes rather than attributed real-world engagements. Each one
walks through a starting state, the Federal Modernization Program
intervention and the behavior to expect. They are framing patterns, not
real engagements.

::: {.callout-important title="Authoring posture"}
Case studies are framing patterns, useful for planning conversations. They
are not citable as deployed-and-validated references.
:::
