# Research gaps for the developer workbook *Building Privileged Access*

Rows 1 to 4 and 10 were found while writing Chapter 01, rows 5 to 9 while writing Chapter 02. Each was researched on Microsoft Learn (MCP tools) or in the repository on October 30, 2026. Where a later chapter depends on one, the outline in `index.md` says so.

| # | Gap | Finding | Status | Source |
|---|---|---|---|---|
| 1 | Does `Get-MgRoleManagementDirectoryRoleAssignment` return every page without `-All`? (Chapter 01) | Learn's all-roles sample passes neither `-All` nor `-PageSize`. The cmdlet's reference page, read on October 30, 2026, lists `-PageSize`; the excerpt read didn't show `-All`. Other Graph PowerShell list cmdlets document `-All` as "List all pages." | open: Chapter 01's code reads through Graph and follows next links, so it doesn't depend on the answer; the gap table states only what the sample passes | Learn, Get-MgRoleManagementDirectoryRoleAssignment; pinned `view-assignments.md` |

Whether `RoleAssignmentSchedule.Read.Directory` alone returns the display name of a user or group principal isn't stated. | open: Lab 2, step 6 records it; the code types an unreadable principal as `unknown` rather than dropping it | Learn, unifiedRoleAssignmentScheduleInstance; List unifiedRoleAssignments |
