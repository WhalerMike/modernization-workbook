# Verification — Chapter 09, Deploying to Test and Production

New material; it replaces no workbook page. The owner asked for a runbook that takes the kit from Lab 2 to a live test tenant, then to production, as exact commands. There is no implementation guide for this track yet, so the chapter is built from the project plan (`docs/project-plans/privileged-access.md`), Chapters 01 to 08 and their code, and Microsoft Learn.

The module imports Chapter 01's `PrivilegedAccess` and calls Chapter 02's `Test-PaEmergencyAccess` and Chapter 01's fake unchanged. The kit README gains a Deploy section. No earlier chapter's code, configuration or tests changed. `scripts/run_example_tests.py` now also finds a kit's `deploy/tests` suite, with a unit test in `scripts/tests/test_check_changed.py`; the deploy tests are kept out of `tests/` so the earlier chapters' "330 tests passing" captures stay true.
