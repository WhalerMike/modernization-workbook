**Why its own runspace.** Inside a `try` block anywhere up the call stack, PowerShell stops a script at a statement-terminating error; Pester runs each test inside one. The page's stray `Example:` line is such an error, so the harness runs the script in a separate runspace, as a `.ps1` file or a console paste would run it, where the error is reported and the script carries on.
