**Why these samples.** Searched on October 30, 2026 with the Learn MCP tools (`microsoft_docs_search`, `microsoft_code_sample_search`). For Active Directory, Learn's service account series is Microsoft's discovery procedure: *Secure user-based service accounts* has the three commands for user accounts, and *Secure group managed service accounts* the `Get-ADServiceAccount` commands; *Govern on-premises service accounts* has the data to collect but no commands, so it's cited, not pinned. For Entra, the code sample search returned Learn's script pages for exporting secrets and certificates first; the all-app-registrations script is the one that also reads owners, so it's pinned and the expiring-secrets and enterprise-app variants are linked from the snapshot. *Securing service principals* holds Learn's `Get-MgServicePrincipal` commands. The Book 04, Chapter 05 inventory script and Book 02's `Get-FMPServiceAccountInventory` are the program's own code, not Microsoft's, and are named as the program's starting points. No `microsoftgraph/*` or `Azure-Samples/*` repository was found that inventories service accounts and workload identities together.

Microsoft Learn pages opened on October 30, 2026 through the Microsoft Learn MCP tools: Secure user-based service accounts in Active Directory; Secure group managed service accounts; Securing service principals in Microsoft Entra ID (source); Govern on-premises service accounts (search excerpts); Governing Microsoft Entra service accounts (search excerpts); Delegated Managed Service Accounts overview, setup and FAQ (search excerpts); Service accounts (Windows Server, password policy; search excerpt); Get-ADServiceAccount (search excerpts); Last-Logon-Timestamp attribute (search excerpt); PowerShell sample: Export secrets and certificates for app registrations; List applications; List owners of an application; List federatedIdentityCredential objects, Get federatedIdentityCredential, Get-MgApplicationFederatedIdentityCredential (search excerpts); List servicePrincipals (search excerpts); List owners of a service principal and Get-MgServicePrincipalOwner (search excerpts); List appRoleAssignments granted for a service principal (search excerpt); List oauth2PermissionGrants (search excerpt); Microsoft.Graph servicePrincipals (Bicep reference, search excerpt); Update servicePrincipal (search excerpts); Federated Identity Credentials - List (REST 2024-11-30); Microsoft.ManagedIdentity userAssignedIdentities/federatedIdentityCredentials template reference (search excerpts); Get-EntraServicePrincipal (search excerpt); Overview of enterprise application ownership (search excerpt); View the service principal of a managed identity (search excerpt); Applications listed in Enterprise applications (search excerpt).
