# Verification — Chapter 13: Workload Identity Across AWS GovCloud (US) and OCI

New chapter, first pass of 2026-11-24, phase 2 of the program owner's decision WD-171 of November 24, 2026 (the Non-Person Identity track extended to the program's AWS GovCloud (US) accounts and OCI tenancy). The implementation guide's Steps 1g, 1h and 4f and its orphan rule (pull request #736) set the rules and the export commands; this chapter implements them and adds only the reads the checks need. Every source was read on November 24, 2026, by direct fetch of the vendor's own page. The kit's Lab 1 was run on the fixtures that day; its output is in the chapter and in `data/kit-captures/npi/13-*.txt`. Lab 2 has not been run by anyone.
