# Verification — Chapter 08, Deploying to a Test Tenant, Then to Production

New material; it replaces no workbook page. Code: `examples/hr-lifecycle/deploy/` (new): `deploy_settings.py`, `preflight.py`, `smoke_test.py`, `rollback.py`, `evidence.py`, `settings.example.json`, `smoke-workers.json`; three GET-only tasks in `config/calls.json` (`deploy-preflight`, `deploy-job`, `deploy-smoke`); `deploy/tests/test_deploy.py` (23 tests; 25 since November 9, 2026) and `deploy/tests/fixtures` (fictional settings for a test and a production tenant, pre-flight exports, and smoke exports for the joiner, mover and leaver phases); the kit README's new section; `.gitignore` (`evidence/`, the environment settings files). `examples/hcm-entra` is unchanged: the runbook calls `hcm_to_scim.py` with a settings file `deploy_settings.py middleware` writes. No Microsoft sample is pinned: Learn publishes no runbook or sample for promoting an HR-driven lifecycle from a test tenant to production.

Test results on November 2, 2026, Windows 11, Python 3.14.3 with pytest: `examples/hr-lifecycle` 57 passed in `tests` (unchanged, so Chapters 01 to 07's captured test step still matches) and 23 passed in `deploy/tests`; `scripts/run_example_tests.py` now also runs a kit's `deploy/tests`; `examples/drift-pipeline` 142 passed (run because `hr-lifecycle` changed). No tenant, no network.

Every fixture-mode output in the chapter was produced on November 2, 2026 by running the commands in `examples/hr-lifecycle` against `deploy/tests/fixtures`, with `out/ch08/...` in place of `"$EVIDENCE/..."` and fixture mode in place of tenant mode, and pasted; `out` was deleted afterwards. `rollback.ps1`'s dry run was run with PowerShell 7 (`pwsh -NoProfile -File`), which printed the commands and changed nothing. `hcm_to_scim.py` was run without `--apply`. Nothing was sent to a tenant, an HR pod or a storage account. **The runbook has not been run against a live tenant**; every live result in the chapter is labeled an expected result.
