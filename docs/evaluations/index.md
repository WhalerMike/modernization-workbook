# Evaluations {.unnumbered}

An evaluation helps you choose: it judges a product, or a set of options, against what a book requires, and records the evidence for and against each. It plays the part of the technology choice guides on Microsoft Learn, such as [Technology choices for Azure solutions](https://learn.microsoft.com/azure/architecture/guide/technology-choices/technology-choices-overview).

The books stay vendor-neutral: they set out what to achieve and why. An evaluation names products because a choice has to be made. Where it recommends one, that is the program's own analysis, not an endorsement by any agency. Each page keeps its status label (draft or in review) until it is reviewed and proved; see [Status labels](../about/sources-and-verification.md#status-labels).
