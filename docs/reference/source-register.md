# Source Register {.unnumbered}

<!-- Generated from data/source-register.json by scripts/source_watch/register.py. Don't edit this page. -->

This register lists 70 sources. A slide or a video description links to a source's row here, and the row links to the original. A deck can't change once it's released, but a row can, so a link in a released deck stays right when a publisher moves a page.

## How the register is controlled

- **A source's address is permanent.** A row can be retired but never deleted or renamed, so a link to it never breaks.
- **Every change is recorded and approved.** A new source, a changed address or a retired row goes through a reviewed pull request, adds a line to the revision history below, and sends this page back to its owner for approval.
- **The weekly scan reads, and never edits.** Each row's address is one the books cite, so the Monday source watch checks it. The **Last scan** column shows the latest result. When a source moves or disappears, the scan proposes the fix in its report and the owner decides.

(function () {
  // The scan's results live on the source-watch-state branch, not on this page, so a
  // weekly scan needs no deploy and leaves the reviewed page alone.
  var LABEL = { ok: "OK", gone: "Gone", blocked: "Needs a manual check", moved: "Moved", error: "No answer" };
  window.fmwRegisterScan = function (scan) {
    document.querySelectorAll(".fmw-scan").forEach(function (cell) {
      var row = scan.sources[cell.getAttribute("data-source")];
      if (!row) { cell.textContent = "Not scanned yet"; return; }
      cell.textContent = (LABEL[row.status] || row.status) + ", " + row.last_checked;
    });
  };
  fetch("https://raw.githubusercontent.com/WhalerMike/modernization-workbook/source-watch-state/data/source-watch/register-scan.json")
    .then(function (r) { if (!r.ok) { throw new Error(); } return r.json(); })
    .then(window.fmwRegisterScan)
    .catch(function () {
      document.querySelectorAll(".fmw-scan").forEach(function (cell) { cell.textContent = "Not available"; });
    });
})();
</script>
