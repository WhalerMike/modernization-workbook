Five gaps were handed to the session that started this book; rows 6 and 7 were found while writing Chapter 07, rows 8 and 9 while writing Chapter 04. Each was researched on Microsoft Learn (MCP tools) or in the repository on October 30, 2026. Where a later chapter depends on one, the outline in `index.md` says so.

Two conflicts found on Learn while writing Chapter 01, recorded here so a later edit doesn't "fix" the code to the looser figure:

- The `/bulkUpload` rate limit is 40 requests per second on the API reference page and 40 calls per 5 seconds on the concepts and troubleshooting pages. The code paces to the stricter.
- The concepts page names `ProvisioningLog.Read.All` for API clients reading provisioning logs; the List provisioningObjectSummary page names `AuditLog.Read.All` and `Directory.Read.All` as least privileged.

Three places where Learn's machine configuration pages and GuestConfiguration 4.12.0 differ, found by running the module while writing Chapter 07 and pinned in `examples/machine-configuration/tests/LearnBaseline.Tests.ps1`. The chapter follows what the module does:

- Learn names the generated definition files `auditIfNotExists.json` and `deployIfNotExists.json`; 4.12.0 writes `<package>_AuditIfNotExists.json` and `<package>_DeployIfNotExists.json`.
- Learn says `-Tag` takes an array of hashtables; 4.12.0 binds one hashtable and refuses an array.
- Learn's expected package contents list the `GuestConfiguration` and `DscNativeResources` modules; a 4.12.0 package holds only the configuration's own resource modules.

One conflict between Learn pages found while writing Chapter 04: the dynamic membership samples page says to resume noncritical collections after at least 12 hours; "Understand and manage dynamic group processing" says to wait a minimum of 24 hours. `examples/dynamic-rules` defaults to 24.
