# Verification — Guide: Zero Trust Assessment

New guide, first pass of 2026-11-11, written for the Zero Trust Assessment closure update's Phase 5 (tracker item ZTA-GUIDE): Mike asked for "a specific implementation guide and presentation on Microsoft Zero Trust Test tool," then "include the training module" (Nov 11, 2026). Microsoft facts were read on Microsoft Learn on 2026-11-11 through the Microsoft Learn documentation service (search and fetch). The tool's behavior was read in its GitHub repository at tag 3.1.0 (the latest release on 2026-11-11, published 2026-10-20): the module manifest, `Connect-ZtAssessment.ps1`, `Invoke-ZtAssessment.ps1`, `Get-ZtAssessmentResults.ps1`, `Get-ZtTestStatus.ps1`, `Get-ZtTestResultStatus.ps1`, `Get-ZtSkippedReason.ps1`, `Add-ZtTestResultDetail.ps1`, `Get-ZtGraphScope.ps1`, `ZtTest.ps1`, `Test-Assessment.50001.ps1`, the 364 test files' attribute headers, the README and `src/powershell/doc/readme.md`; the repository's `SampleReport.json` (synthetic demo data from 2.5.0) was read for the export's shape. AWS facts were read through the AWS documentation service the same day. No personal name, email address, agency or tenant detail was sent in any request. Nothing was run against a tenant; the kit (`examples/zta-results`) was run against its fictional fixtures (51 Pester tests pass).

Facts carried from the books (Book 11 Chapters 05, 07, 08, 09, 10; Book 13 Appendix A's KSI mappings; Book 15 Chapter 12's cadence) are cited by link and rely on those pages' own verification logs.
