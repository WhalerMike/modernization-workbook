## The brief

<!-- form-start -->
**The point:** the dates are set outside the agency and they all land on the same estate. One program can sequence them. Separate projects can only race them.

**The clocks**

| Clock | Date | What it asks |
|:----------|:---------|:-------------|
| OMB M-26-14 Agency Logging Plan | November 18, 2026 (calculated) | Then maturity Levels 1, 2 and 3 by December 18, 2026, February 16, 2027 and July 6, 2027 (calculated; confirm with the CISO's office) |
| Windows Server 2016 end of support | January 12, 2027 | The workbook plans on these being gone; any that remains is an exception |
| CISA BOD 26-02 | February 5, 2027 | Decommission listed end-of-support edge devices |
| Windows Server 2019 end of support | January 9, 2029 | The next upgrade, on a date already set |

Running past end of support becomes a risk acceptance an authorizing official has to sign.

**The cost**

- The first step is a four-week pre-flight with no vendor decision. It produces an inventory, an owner and a date.
- The program has no license of its own, but the services it uses do: Microsoft Entra ID P1 for Conditional Access, and P2 or Entra ID Governance for Privileged Identity Management.
- Budget lines that treat the work as independent will produce independent answers to shared questions. Fund and govern it as one sequence.

**What we ask of you**

- Own scope, funding and sequence with the executive sponsor.
- Support the four-week pre-flight, with a named sponsor, a named steward and a date.
- Keep Gate G5, the retirement of Active Directory, as a decision you make with the sponsor.
