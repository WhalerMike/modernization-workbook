# Master Project Plan

Structure, gates, and deliverables for a modernization program.

## Purpose

A reference structure for planning and tracking a multi-year identity and infrastructure modernization program. Adapt phases and gates to the specific estate; the structure is the reusable element.

## Phases

| Phase | Focus | Typical gate |
|-------|-------|--------------|
| 0 | Discovery and baseline | Inventory complete; residual risk register opened |
| 1 | Target architecture and sequencing | Architecture approved; dependencies mapped |
| 2 | Pilot | Pilot population verified; rollback tested |
| 3 | Scale | Wave completion criteria met; evidence collected |
| 4 | Optimize and retire | Legacy components retired or explicitly retained |
| 5 | Steady state | Continuous monitoring and drift detection operational |

## Deliverables per phase

- Phase 0: Assessment reports, dependency map, risk register
- Phase 1: Target architecture, migration sequence, governance model
- Phase 2: Pilot results, refined runbooks, exception list
- Phase 3: Wave reports, residual risk updates, training records
- Phase 4: Retirement evidence, updated architecture
- Phase 5: Operating procedures, monitoring dashboards, review cadence

## Governance

- Executive sponsor and program owner named
- Change control for architecture and sequencing decisions
- Regular residual risk review
- Evidence retained for each gate
