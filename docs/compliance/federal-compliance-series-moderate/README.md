## Engine-neutral by design

The series speaks only to an open Evidence & Authorization Contract that any conformant evidence engine can satisfy. It stands alone without any particular identity or modernization substrate.

## One lifecycle

Every operational change — Move, Add, Change, Deletion, and Reset — travels the same five-clause authorized path:

1. It originates with the authoritative source.
2. It carries an authoritative authorization.
3. It executes under least privilege with just-in-time elevation.
4. It closes with provenance.
5. It emits verified, secured evidence automatically to continuous monitoring.

No closure counts unless it carries its proof.
