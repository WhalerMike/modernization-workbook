Every workbook book has a 15-minute briefing that follows the book's four questions: **Why** the topic matters, **What** changes, **Who** owns it, and **How** to do it. Each deck carries full speaker notes, and every slide names the chapter and the primary sources behind it.

- **Deck**: the editable PowerPoint file, for presenting live.
- **Narrated**: the same deck with recorded narration on every slide, set to play by itself.
- **Script**: the narration as text, for practice or for reading instead of watching.
- **Captions**: the narration as timed WebVTT captions. Every narrated deck carries them built in; the `.vtt` file is the same captions for a video player.

## Accessibility

Every deck is built to meet Section 508 and WCAG 2.1 AA, and an automated check runs on each one before it is published.

- **Captions.** Each narrated deck has closed captions for every slide's narration, built into the file. In the slide show, turn them on with the captions button on the media controls, or set **Slide Show › Always Use Subtitles**. The same captions are published as a `.vtt` file for video players, Microsoft Stream and SharePoint.
- **Transcripts.** The narration script is the full text of the narration, and each slide's speaker notes carry it too.
- **Screen readers.** Every slide has a unique title, read first. Tables mark their header rows. Decorative icons and shapes are marked so screen readers skip them, and the narration audio is described. All text is tagged as English.
- **Contrast and type.** Text meets WCAG contrast against the white background, nothing is smaller than 10 point, and color is never the only signal: the Why, What, Who and How tags carry their words.

If something in a deck isn't accessible to you, open an issue in the [repository](https://github.com/WhalerMike/modernization-workbook/issues) and it will be fixed.

## How the decks are built

The decks are generated from each book's chapters by small scripts in the repository's [`presentations/`](https://github.com/WhalerMike/modernization-workbook/tree/main/presentations) folder, using a shared theme and narration kit in [`presentations/_build/`](https://github.com/WhalerMike/modernization-workbook/tree/main/presentations/_build). When a chapter changes, its deck is rebuilt from the same source.
