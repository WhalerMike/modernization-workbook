# Chapter 06: PIM for Azure resources

Notes for the code behind the developer workbook *Building Privileged Access*, [Chapter 06](../../../docs/project-plans/developer-workbooks/privileged-access/06-pim-for-azure-resources.md). The chapter explains the design, the labs and the Learn sources; this page lists the files.

| File | What it is |
|---|---|
| `powershell/PaAzurePim/PaAzurePim.psm1` | The module. Imports Chapter 01's `PrivilegedAccess` for the cloud table, the tier map, `Get-PaAzureTier` and the paged, host-checked `Invoke-PaList`; never edits it. |
| `config/calls-ch06.json` | The Resource Manager calls, API version `2020-10-01`, each with its least-privileged Azure role and Learn page. Two tasks: `azure-pim-read` (GET only, Reader) and `azure-pim-apply` (adds two PUTs and a PATCH, User Access Administrator). |
| `Invoke-PaAzurePim.ps1` | The entry script. A dry run unless `-Apply`. Writes `state.json`, `plan.json`, `diff.txt`, `findings.json` and `manifest.json`; with `-Apply`, also `diff-after.txt` from a fresh read. |
| `tests/AzurePim.Tests.ps1` | Pester 5 tests: Microsoft's pinned REST examples replayed through the code, then the read, the desired state, the plan, the dry run and the apply against the fake. |
| `tests/fixtures/ch06/estate.json` | The fictional `contoso.example` estate the fake serves: one management group, a workload and a control-plane subscription, and a resource group. |
| `tests/fixtures/ch06/desired.json` | The reviewed desired state: scopes, governed roles, control-plane subscriptions, settings per tier, eligible assignments and standing exceptions. |
| `../third_party/azure-pim-rest-examples` | Microsoft's REST examples for these calls, pinned unmodified with `snapshot.json`. |

## Run it

```powershell
# Lab 1: no tenant, nothing sent
./Invoke-PaAzurePim.ps1 -Cloud gcc -FixturePath tests/fixtures/ch06/estate.json -DesiredPath tests/fixtures/ch06/desired.json `
    -CallerPrincipalId c3000000-0000-4000-8000-000000000003 -OutputPath out/ch06 -RunId lab
Invoke-Pester -Path tests/AzurePim.Tests.ps1
```

## Findings

| Rule | Severity | What it flags |
|---|---|---|
| PA-AZ-01 | Finding (Info on the exceptions list) | Standing (permanent active) Owner, Contributor or User Access Administrator, or another governed role |
| PA-AZ-02 | Finding | A standing assignment held by a service principal or managed identity, which can't be made eligible |
| PA-AZ-03 | Finding | User Access Administrator at root scope (`/`): elevated access, removed rather than converted |
| PA-AZ-04 | Warn | An eligibility on a governed role that isn't in the desired state, or that never expires |
| PA-AZ-05 | Finding | A standing assignment held by the identity the plan runs as; never removed by the plan |
| PA-AZ-06 | Finding | More than three Owners on a subscription, eligible or active, after the plan |

The plan writes to a tenant only through `Invoke-PaAzPlan -Apply` with an `azure-pim-apply` client. Illustrative code: tested against fixtures and a fake, not a production tenant.
