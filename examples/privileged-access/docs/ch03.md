# Chapter 03: Conditional Access for administrators and the activation gate

Notes for the code behind the [developer workbook *Building Privileged Access*, Chapter 03](../../../docs/project-plans/developer-workbooks/privileged-access/03-conditional-access-for-administrators.md). The chapter has the why, the labs and the sources; this page is the map of the files.

Unlike Chapters 01 and 02, this code can write to a tenant. It writes only with `-Apply`, creates every new policy report-only, enforces a policy only with `-AllowEnforce` as well, and never deletes anything.

## Files

```
Invoke-PaCaAdmin.ps1                              the entry script: pre-merge check, plan, dry run or apply, manifest
config/calls-ch03.json                            every call: method, v1.0 path, least-privileged permission, Learn page
powershell/PaConditionalAccess/                   the module (imports Get-PaCloud from PrivilegedAccess)

ca-policies/contexts/c1.json, c2.json             authentication contexts: PIM activation, protected actions

tests/fixtures/ch03/tenant-map.json               placeholder to object ID, for contoso.example
```

## Permissions

| Task | When | Microsoft Graph application permissions |
|---|---|---|
| `ca-read` | Every run without `-Apply` | `Policy.Read.All`, `AuthenticationContext.Read.All`, `Policy.Read.AuthenticationMethod` |
| `ca-apply` | `-Apply` | The three above, plus `Policy.ReadWrite.ConditionalAccess` and `AuthenticationContext.ReadWrite.All` |

`Get-PaCaRequiredPermission -Task ca-read` (or `ca-apply`) prints them. Delegated, the read needs Security Reader (Learn doesn't list Global Reader for the authentication strengths read), and the write Conditional Access Administrator or Security Administrator.

## Rules

| Rule | Severity | What it checks |
|---|---|---|
| PA-CA-01 | Finding; Info | Every policy that isn't disabled excludes the emergency access group; a named report-only instrument without it is Info |
| PA-CA-02 | Finding | A report-only instrument set to enabled |
| PA-CA-03 | Finding | An unresolved placeholder, or a user target that isn't an object ID or a Graph keyword |
| PA-CA-04 | Warn | An authentication context policy that isn't On |
| PA-CA-05 | Finding | An authentication context policy that also targets directory roles |
| PA-CA-06 | Finding; Warn | MFA and an authentication strength together; administrator roles with plain MFA |
| PA-CA-07 | Warn | A policy targeting roles that leaves out any of the 14 Learn recommends |
| PA-CA-08 | Finding | A context outside `c1` to `c25`, or a policy naming a context the repository doesn't define |
| PA-CA-09 | Warn | A report-only compliant-device policy that doesn't exclude Android, iOS and macOS |
