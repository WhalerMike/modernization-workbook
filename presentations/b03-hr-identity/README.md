# Book 03 — HR-Driven Identity: presentation

The 15-minute Why / What / Who / How briefing for [Book 03](../../docs/books/b03-hr-identity/index.md), built with the shared kit in [`../_build/`](../_build/README.md). Its framing follows the agency-neutral interview deck in [`../hr-driven-identity-interview/`](../hr-driven-identity-interview/README.md), re-pointed at the book's chapters and its verified facts. This folder sits outside `docs/`, so the site doesn't render it.

| File | Use |
|---|---|
| `B03_HR_Identity.pptx` | The deck: eleven narrated slides, then a backup section with the full source list |
| `B03_HR_Identity_Narrated.pptx` | Self-running version with the narration embedded and slide timings set |
| `B03_HR_Identity_Narration_Script.md` | The narration text, for practice |
| `narration_B03_HR_Identity/` | Per-slide audio and durations |
| `build.js` | Slide content and speaker notes; rebuild with the commands in `../_build/README.md` |

Every fact on the slides comes from a footnoted chapter of Book 03; each slide's notes name the chapter, and the last slide lists the primary sources.
