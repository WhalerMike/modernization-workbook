# Book 02 — Identity & Directory: presentation

The 15-minute Why / What / Who / How briefing for [Book 02](../../docs/books/b02-identity/index.md), built with the shared kit in [`../_build/`](../_build/README.md). This folder sits outside `docs/`, so the site doesn't render it.

| File | Use |
|---|---|
| `B02_Identity.pptx` | The deck: twelve narrated slides, including the four-tracks slide that says what Book 02 moves and which books carry the rest, then a backup section with the full source list |
| `B02_Identity_Narrated.pptx` | Self-running version with the narration embedded and slide timings set |
| `B02_Identity_Narration_Script.md` | The narration text, for practice |
| `narration_B02_Identity/` | Per-slide audio and durations |
| `build.js` | Slide content and speaker notes; rebuild with the commands in `../_build/README.md` |

Every fact on the slides comes from a footnoted chapter of Book 02; each slide's notes name the chapter, and the last slide lists the primary sources.
