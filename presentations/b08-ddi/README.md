# Book 08 — DNS, DHCP & IPAM: presentation

The 15-minute Why / What / Who / How briefing for [Book 08](../../docs/books/b08-ddi/index.md), built with the shared kit in [`../_build/`](../_build/README.md). This folder sits outside `docs/`, so the site doesn't render it.

| File | Use |
|---|---|
| `B08_DDI.pptx` | The deck: fourteen narrated slides, then a backup section with the full source list |
| `B08_DDI_Narrated.pptx` | Self-running version with the narration embedded and slide timings set |
| `B08_DDI_Narration_Script.md` | The narration text, for practice |
| `narration_B08_DDI/` | Per-slide audio and durations |
| `build.js` | Slide content and speaker notes; rebuild with the commands in `../_build/README.md` |

Every fact on the slides comes from a footnoted chapter of Book 08; each slide's notes name the chapter, and the last slide lists the primary sources. The timing cue at the start of each slide's notes is worked out by `build.js` from the spoken words at about 142 words a minute, so it stays right when the notes are edited.
