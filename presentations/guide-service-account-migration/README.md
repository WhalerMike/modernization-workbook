# Companion guide — Service Accounts: From User Accounts to gMSAs to Microsoft Entra Workload Identities

**Deck name: Guide_Service_Account_Migration.** The narrated deck for the companion guide [Service Accounts: From User Accounts to gMSAs to Microsoft Entra Workload Identities](../../docs/books/guides/service-account-migration.md), built with the shared kit in [`../_build/`](../_build/README.md) and the companion-guide slide helpers in [`../attribute-driven-migration-technical-part-1/slides.js`](../attribute-driven-migration-technical-part-1/slides.js). It's for Active Directory and identity engineers, application owners and the ISSOs who review their evidence. It teaches the same guide as [Module 12](../../docs/training/non-person-identity/12-service-account-migration.md) of the Non-Person Identity learning path, and its managed service account standard as [Module 13](../../docs/training/non-person-identity/13-the-managed-service-account-standard.md). This folder sits outside `docs/`, so the site doesn't render it.

The plain and narrated decks join the next edition's Release; until then, build them from this folder. The video runs about 27 minutes. The narration was re-recorded on November 21, 2026, from the guide as approved on November 20, 2026, when it gained the managed service account standard, and slides 5, 6, 11 and 14 again on November 22, 2026, after the guide's decision path was reordered (questions 1 to 8 in order, with the Keep and KeepKerberos exceptions before the dMSA and gMSA questions), the dMSA wait reworded and the request step made consistent (SailPoint approves; ServiceNow records). If the guide changes, the deck is rebuilt and re-recorded.

Build (Git Bash): `source /c/tmp/deckenv.sh`, then `FIT=1 node presentations/guide-service-account-migration/build.js presentations/guide-service-account-migration/Guide_Service_Account_Migration.pptx`. Then `narrate.py` and `captions.py`, and on a workstation where PowerPoint is free, `qa_export.ps1`, `build_narrated.ps1` and `export_mp4.ps1`, as in the kit's README. The build runs the shared checks: title length and uniqueness, Sources length, and overflow warnings, including the code panels' width and height.

## Notes and sourcing

Each slide's speaker notes are the narration, then a `Workbook:` reference to the guide's sections, which isn't spoken. The narration names each source by its original, Microsoft Learn, and spells out the acronyms the voice would misread (G M S A, D M S A, K D S, S P N, I S S O). Every fact on a slide comes from the guide, which footnotes each one to the Microsoft Learn page it was read from on November 9, 2026, or for the mail section and the gMSA decisions on November 11, 2026, and for the managed service account standard (NIST SP 800-53, FedRAMP's KSIs, CISA's Zero Trust Maturity Model, SailPoint, Defender for Identity) on November 20, 2026 (the pages and their dates are in the guide's [verification log](../../docs/books/guides/_verification/service-account-migration.md)), or from the Non-Person Identity developer workbook chapters the guide links; the deck adds none. The commands on the slides are the guide's, which are Learn's, with the guide's placeholders; long ones are continued PowerShell-style with a backtick. The guide's labels carry over: the program's rules, the managed service account standard, the 30-day parallel run, the decision path's dispositions and the KSI mapping are design guidance; and the deck says evidence *supports* a requirement, as the guide does. The commands weren't run against a domain or a tenant for the guide; the Learn procedures run against stand-ins in the kit's tests, as Module 12's lab shows.
