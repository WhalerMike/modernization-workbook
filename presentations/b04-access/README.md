# Book 04 — Access & Privilege: presentation

The 15-minute Why / What / Who / How briefing for [Book 04](../../docs/books/b04-access/index.md), built with the shared kit in [`../_build/`](../_build/README.md). This folder sits outside `docs/`, so the site doesn't render it.

| File | Use |
|---|---|
| `B04_Access.pptx` | The deck: ten narrated slides, then a backup section with the full source list |
| `B04_Access_Narrated.pptx` | Self-running version with the narration embedded and slide timings set |
| `B04_Access_Narration_Script.md` | The narration text, for practice |
| `narration_B04_Access/` | Per-slide audio and durations |
| `build.js` | Slide content and speaker notes; rebuild with the commands in `../_build/README.md` |

Every fact on the slides comes from a footnoted chapter of Book 04; each slide's notes name the chapter, and the last slide lists the primary sources.
