# Book 07 — PKI & Certificates: presentation

The 15-minute Why / What / Who / How briefing for [Book 07](../../docs/books/b07-pki/index.md), built with the shared kit in [`../_build/`](../_build/README.md). This folder sits outside `docs/`, so the site doesn't render it.

| File | Use |
|---|---|
| `B07_PKI.pptx` | The deck: thirteen narrated slides, then a backup section with the full source list |
| `B07_PKI_Narrated.pptx` | Self-running version with the narration embedded and slide timings set |
| `B07_PKI_Narration_Script.md` | The narration text, for practice |
| `narration_B07_PKI/` | Per-slide audio and durations |
| `build.js` | Slide content and speaker notes; rebuild with the commands in `../_build/README.md` |

Every fact on the slides comes from a footnoted chapter of Book 07; each slide's notes name the chapter, and the last slide lists the primary sources.
