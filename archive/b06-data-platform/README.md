# Archive — Book 06 source pages

The SQL Server Identity Transformation narrative series (`docs/case-studies/sql-server-narrative/`), its Implementation Companion (`docs/sql-server-implementation/`) and the SQL Server case-study summary became [Book 06 — Data Platform: SQL Server Identity](../../docs/books/b06-data-platform/index.md) on October 20, 2026. The pages are kept here, unchanged and at their original relative paths. They are **not published**: `_quarto.yml` excludes `archive/`, every old address forwards to the book (`scripts/redirects.yml`), and the old Word download names (`sql-server-narrative-bundle.docx`, `Book_NN-bundle.docx`, `Applicability-bundle.docx`, `Appendix_A/B-bundle.docx`) are aliases of the new bundles (`scripts/bundles.yml`). The series' diagrams stay in `docs/images/sql-server/diagrams/`, which the book uses.

The book flattened the narrative's books into Chapters 01–23, added Chapter 13 (Who Owns the Data Platform), turned the companion's books into Runbooks R01–R10, and folded each book's short front page into the first chapter of its part. What each page kept or corrected is recorded in `docs/books/b06-data-platform/_verification/`.
